# Luana Bispo Advocacia

Site institucional de Luana Bispo Advocacia — Direito de Família e Direito do Consumidor (Rio de Janeiro).

Site estático em HTML/CSS puro, uma única página (`index.html`), sem dependências de build.

## Publicar no GitHub Pages
1. Vá em **Settings > Pages** neste repositório.
2. Em "Source", selecione a branch `main` e a pasta `/root`.
3. Salve. O site fica disponível em `https://<seu-usuario>.github.io/<nome-do-repositorio>/`.
